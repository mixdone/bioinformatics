# Задание 4

В качестве инструмента для отображения был выбран [Jsmol](https://chemapps.stolaf.edu/jmol/jsmol/jsmol.htm?_USE=HTML5). Белок над которым буду издеваться - [2H5Q](www.rcsb.org/structure/2H5Q).

Для отображения белка загружаем файл в формате pdb на сайт. В дальнейшем работаю через консоль.
